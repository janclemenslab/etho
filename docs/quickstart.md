# Quickstart

This page is the shortest path from a fresh environment to a local Etho smoke
test. It uses the dummy camera protocol generated by `etho init`, so it does not
require a physical camera or DAQ device.

## Activate Etho

Use the conda environment that contains Etho:

```shell
conda activate etho
etho --help
```

The command should list the current subcommands:

```text
usage: etho [-h] {version,init,run,gui} ...
```

If `etho` is not found, follow the [installation guide](install.md) before
continuing.

## Initialize Config Files

Create the default user configuration, folders, a dummy protocol, and a simple
playlist:

```shell
etho init
```

By default this creates:

- `~/ethoconfig/ethoconfig.yml`
- `~/ethoconfig/protocols/dummy_1min.yml`
- `~/ethoconfig/playlists/0_silence.txt`
- `~/ethoconfig/stim/`
- `~/data/`

`etho init` does not overwrite an existing `~/ethoconfig/ethoconfig.yml`.
Delete or edit that file manually if you need to regenerate the global
configuration.

## Inspect the Generated Files

Check the global paths:

```shell
cat ~/ethoconfig/ethoconfig.yml
```

Check the dummy camera protocol:

```shell
cat ~/ethoconfig/protocols/dummy_1min.yml
```

The generated protocol uses the `GCM` camera service with `cam_type: Dummy`.
That makes it suitable for checking the control flow before connecting rig
hardware.

## Run a Dummy Experiment

Run the generated protocol:

```shell
etho run ~/ethoconfig/protocols/dummy_1min.yml --save-prefix quickstart_dummy
```

The run writes data and logs under the configured `savefolder`, usually
`~/data/quickstart_dummy/`. A display window may open because the generated
dummy protocol includes an image-display callback.

For a camera preview without saving experiment data:

```shell
etho run ~/ethoconfig/protocols/dummy_1min.yml --preview
```

## Check Runtime Support

Use `etho version` to print Python, package, GUI, and optional hardware support:

```shell
etho version
etho version --debug
```

Missing optional SDKs are expected on a laptop or workstation that is not
connected to a rig. Treat missing entries as blockers only for the hardware you
intend to operate.
